# Alberta referendum

Research files for Alberta referendum votes and polls. The folder layout follows [Rohan Alexander's starter folder](https://github.com/RohanAlexander/starter_folder). Scripts are Python rather than R.

Remote: <https://github.com/TheZarif/alberta-referendum>

## File structure

- `data/00-simulated_data` contains a simulated division-level file, used to check the pipeline before the official workbooks are downloaded.
- `data/01-raw_data` contains the Elections Alberta workbooks and the 338Canada poll snapshot, as obtained.
- `data/02-analysis_data` contains the cleaned datasets.
- `other` contains source notes, LLM usage, saved sketches, and `collaborator/` (the original Colab notebook behind script 06, kept for reference only).
- `notebooks` contains the spatial analysis write-up for readers who don't code: a Jupyter notebook with outputs saved, the same content as a Quarto document, and the rendered web page (`06-spatial_analysis.html`). All three are generated by `build_06_spatial_analysis.py`.
- `scripts` contains the Python scripts, run in number order.

`paper/` and `models/` from the starter are not included. There is no paper and no fitted model yet.

## Setup

From the project root, with the virtual environment activated:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/00-simulate_data.py

```

## Spatial analysis

The spatial analysis has two parts. Part 1 asks where question 10's Option 2 (start the process toward a binding separation referendum) was strongest, whether support is geographically clustered, whether that clustering is more than the city-versus-country divide, and whether turnout mattered. Part 2 compares all ten questions: how each did by riding and region, whether they share one geography (they do, almost exactly), and which ridings voted differently on question 10 than their other answers would predict.

- `notebooks/06-spatial_analysis.html` is the version to read: a self-contained web page with captions written for non-programmers. The code boxes can be collapsed.
- `notebooks/06-spatial_analysis.ipynb` and `notebooks/06-spatial_analysis.qmd` are the same analysis as a Jupyter notebook and a Quarto document.
- `scripts/06-spatial_analysis.py` prints the key statistics and saves three figures to `other/sketches/`.
- `scripts/spatial.py` holds the loading and statistics code that the script and notebooks share.

Methods: "support" is the Yes share for questions 1 to 9 and the Option 2 share for question 10. Global Moran's I with shared-border (queen) neighbours and a 9,999-permutation test, checked against 3 to 10 nearest neighbours. Moran's I is computed again after removing each region's average. Local Moran's I (LISA) uses conditional-permutation p-values. The figure captions are computed from the results, so they update if the data change.

To edit the notebooks, change `notebooks/build_06_spatial_analysis.py`, then regenerate, run and render (needs [Quarto](https://quarto.org)):

```bash
python notebooks/build_06_spatial_analysis.py
```

```bash
cd notebooks && python -m jupyter nbconvert --to notebook --execute --inplace 06-spatial_analysis.ipynb && QUARTO_PYTHON=../.venv/bin/python quarto render 06-spatial_analysis.qmd
```

The analysis was adapted from a collaborator's Colab notebook, kept in `other/collaborator/` for reference. Differences from that notebook:

- Votes come from `ed_results_2026.csv`, not pasted values.
- Boundaries are the 2017 electoral divisions from the Government of Alberta (`data/01-raw_data/ab_electoral_divisions_2017.geojson`, simplified), replacing the notebook's Voronoi polygons and approximate points. Divisions are joined to results by division number.
- Region labels (`data/01-raw_data/ed_regions.csv`) were carried over from the notebook and not independently verified.
- The notebook's OLS/SAR regression was dropped: its covariates (oil and gas share, "Wildrose baseline", migration) were random numbers. Add real covariates before fitting one.
